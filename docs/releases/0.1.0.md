# runtime-v0.1.0

This stable release promotes the already qualified `runtime-v0.1.0-rc3`
runtime payloads unchanged. The runtime archives and qualification records remain
bound to producer revision `91423af1a1ae36221440ccc2475c1c88758d6d9f`.

## Consumer-kit note

RC3 downstream qualification exposed a Linux-only false negative in the
consumer-kit relocation check: `readlink -f` canonicalized the FEniCS OpenBLAS
provider through the packaged `runtime -> .` symlink, while the comparison root
remained noncanonical. The runtime payload was valid; no runtime artifact needed
rebuilding. The consumer-kit fix canonicalizes that root before the provider
check (`4be16e955706a5860daee8e29f710f19e4b205ab`, merged on `main` as
`49f608c4867eedc74d48eb223add8f7bb0e6debb`). Stable-tag receipt support was
added in `9ab78d1ce4d9edb56ec30fe38399d5f5fe51a3ad` (merged as
`63cda6fbeb95feeba3830b48c915b6a196e54d95`), so consumers integrating
`runtime-v0.1.0` should vendor that consumer-kit revision or later.
